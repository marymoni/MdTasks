# Task Statistics Requirements

The page must include a sub-header with task statistics.

The statistics sub-header must be a horizontal line with these values:

- `Total #` - total count of tasks.
- `WIP #` - count of tasks with status `0 - WIP`.
- `Pending #` - count of tasks with status `1 - Pending`.
- `Done #` - count of tasks with status `3 - Done`.

Statistic values must refresh together with task values shown in the table.

Statistics must be calculated solely on the client side.
